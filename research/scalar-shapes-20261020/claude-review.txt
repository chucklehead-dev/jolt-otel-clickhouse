**Ownership/policy/fallback ordering:** `any_value.clj`'s converter tries root-identity cache → `original-try-scalar-string-map` (plain maps) → `shape-lookup` (fast path) → `original-try-sorted-scalar-string-map` + `learn!` (slow path, learn only after original admission succeeds). **No stale telemetry in plans:** `compile-one`'s template (`plan.ss`) is built once from static schema keys with ordinal placeholders via ordinary `tmap-put!`; no input values are stored in the template. Each lookup clones only hash geometry (`copy-node`/flat-array clone) and substitutes freshly-converted values per call — no value retention across calls, matching the docstring and `experimental_test.clj`'s freshness assertions (`not identical? one two`).

**Fixed-key hash/collision/order cloning:** `copy-node` preserves `hnode`/`hcoll` bitmap/alist/hash structure exactly, substituting only leaf values by ordinal; the flat pmap-array branch is handled symmetrically. `fill!` enforces strict in-order key match against the schema's recorded order, so a differently-ordered same-keyset map safely declines to the slow path rather than risk misordering — verified by the reverse-comparator test case in `experimental_test.clj`.

**Malformed/cycle rejection:** Both `fill!` (plan.ss) and `collect-keys` (planner.ss) bound traversal via a monotonic `seen` counter checked before each recursive step, so corrupted `:cnt`/`:tree` fields and injected cyclic pvecs terminate without unbounded recursion — directly tested in `malformed-and-custom-inputs-never-run-callbacks`, including a zero-callback-count assertion proving no comparator/`:seq` is invoked.

**Eight original roots / root-cache bounds:** `scalar-string-map-payload-bindings` supplies the same 8 anchors to both the root cache and the shape planner; `all-original-policy-roots-still-fence-cold-plan-and-root-hits` confirms any single root mutation blocks both paths.

**No callback/comparator bypass, no silent downgrade:** Confirmed by the zero-calls test above and by `chdb.clj`'s `exporter` validations, which throw (rather than silently fall back) when `:experimental-span-shape-plans?` is requested without the codec/payload-cache prerequisites, and when the native factory can't be resolved (`ns-resolve` stubbed in `invalid-or-missing-capability-rejects-before-storage-without-canary`).
